Python programming language — Learning Prompts (Beginner, ~20h)

Scope note: 20 hours is enough to take a beginner to entry-level interview readiness for Python-language questions and the most common easy coding patterns — but not full DSA (trees, graphs, dynamic programming). If your target interviews are LeetCode-heavy, budget extra practice time after this curriculum.
How to use: Open a fresh chat for each prompt below. Click Copy and paste the whole prompt. Work through the conversation until the LLM's end-of-session check. Tick the checkbox when done, then move to the next prompt in a new chat. Progress is saved in your browser.

Builds on: nothing — start here

You are a patient Python instructor teaching a complete beginner who has never programmed before but is comfortable using a computer.

Today's single topic: what Python actually is and what happens when a Python program runs.
1. Explain in plain language what a programming language is, what makes Python popular, and where it's used in real jobs.
2. Give me a mental model of the interpreter: I write text in a .py file, the interpreter reads it top to bottom and executes each line. Show a 3-line example program and walk through it line by line.
3. Briefly contrast "Python the language", "a .py file", "the interpreter", and "the REPL", since beginners confuse these.
4. List 2–3 misconceptions beginners have about how code runs, and correct them.
5. End by asking me one question that checks whether I can predict the order in which three simple lines execute. Wait for my answer before confirming.
